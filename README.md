# Mental Health Resources for Youth Athletes

This repository hosts a lightweight web page with curated support links and a chatbot proof-of-concept for young athletes. It now also includes a detailed production guide for creating **The Resilient Athlete: 8-Week Mental Resilience Curriculum** PDF package.

## Contents
- `index.html` – Static site with crisis hotlines, clinic links, a searchable resource list, and a simple client-side chatbot.
- `Resilient_Athlete_Handbook_Production.md` – Step-by-step specifications and quality criteria for building the 72-page handbook and exporting color, B&W, and print-ready PDFs.

## Usage
Open `index.html` in a browser to view the resource page. Use the production guide to design and export the handbook following the defined typography, color palette, layout, and workflow.
